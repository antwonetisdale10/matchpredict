What's fitted, what's assumed

Learned from 20 seasons of results

  • Team attack and defence strength, plus home advantage, using a time-weighted Poisson model with the Dixon–Coles low-score fix (half-life 1.5 years)
  • How goals split between the first and second half (about 44% before the break)
  • Each team's yellow cards, reds, corners, shots and fouls, on the same footing

Assumptions, because the data can't tell us

  • The match CSVs have no goal minutes, so timing within each half uses a standard rising-intensity curve and typical stoppage time
  • Scorers and booked players come from last season's player numbers, not from this season's matches
  • The penalty rate is a flat prior of about 0.28 per game, scaled by shot volume
  • No injuries, suspensions, managers or referee; player shares use last season's numbers on the current squad. Teams with no recent top-flight data use a newly-promoted prior
